# Brag Skill

Turn codebases and web projects into high-octane product launch videos.

## Workflow

1. **Inspect**: Analyze repository architecture, tech stack, routes, key unique mechanics, design tokens, and value proposition.
2. **Plan**: Formulate the angle, tone (`polished`, `cyberpunk`, `cinematic`, `yc-parody`), and 15-25 second storyboard into `brag-output/brag-plan.md`.
3. **Compose**: Build the composition in `brag-output/composition/index.html` with audio, animations, real-time preview, and video export.
4. **Deliver**: Output video (`brag.mp4` / `brag.webm`), hero poster (`brag.jpg`), and viral social copy (`share-copy.txt`) into `brag-output/`.
